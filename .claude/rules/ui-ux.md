# TiemHoaWeb UI/UX rules

Before meaningful UI changes, read `docs/03_UX_UI_SPEC.md` and `docs/04_DESIGN_SYSTEM.md`.

Primary verification viewport is 390x844; also check 360px width. Critical controls cannot depend on hover. Minimum touch target is 44x44 CSS px. Preserve reduced-motion behavior and avoid dashboard-like visual density.
