# UI Review Prompt

```text
Act as a strict mobile game UI/UX reviewer for TiemHoaWeb.

Read docs/03_UX_UI_SPEC.md and docs/04_DESIGN_SYSTEM.md, then inspect the running UI at 390x844 and 360x800.

Review only; do not immediately redesign everything.

Evaluate:
- visual hierarchy;
- bouquet/customer focus;
- one-handed reachability;
- touch targets;
- text wrapping in Vietnamese;
- density;
- whether it feels like a cozy game rather than a dashboard;
- feedback/motion;
- accessibility;
- safe-area and overflow;
- clarity of the primary action.

Return issues grouped as P0 / P1 / P2 with evidence and the smallest concrete fix for each. Do not give generic design advice.
```
