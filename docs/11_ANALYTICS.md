# Analytics Plan — Post-Prototype

Analytics is optional for the earliest local prototype. If introduced, keep events minimal and product-oriented.

## Core funnel events

- `game_started`
- `first_order_opened`
- `flower_added`
- `bouquet_delivered`
- `reaction_viewed`
- `diary_opened`
- `share_card_generated`
- `share_started`
- `day_completed`

## Useful properties

Do not include personal identifiers.

Examples:

- day number;
- order occasion;
- bouquet stem count;
- satisfaction tier;
- score bucket;
- session elapsed bucket;
- platform/browser family where privacy policy permits.

## Product metrics

Primary early metrics:

- First-order completion rate.
- Median time to first bouquet delivery.
- Second-order start rate.
- Day-1 completion rate.
- Diary open rate after first bouquet.
- Share-card generation rate.

Do not optimize for raw session length if it comes from friction.
