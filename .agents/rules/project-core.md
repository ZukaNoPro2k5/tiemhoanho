# TiemHoaWeb Core Rule

Follow `AGENTS.md`.

Before major product work, consult `docs/01_PRD_MVP.md`. Preserve the product priority: UI/UX and bouquet delight before feature breadth.

Do not introduce backend accounts, game engines, multiplayer, gacha, energy systems or large management systems without an explicit decision update.

For completed code changes, verify lint, typecheck, tests and mobile layout.
