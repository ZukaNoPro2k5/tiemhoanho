# UI/UX Rule

Read `docs/03_UX_UI_SPEC.md` and `docs/04_DESIGN_SYSTEM.md`.

Verify 390x844 first, then 360px width. Minimum interactive target is 44x44 CSS px. No hover-only critical behavior. Respect safe-area insets and reduced motion.

Avoid SaaS/dashboard visual patterns. Keep bouquet/customer imagery visually dominant and keep the primary action obvious.
